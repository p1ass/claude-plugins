# claude-plugins

p1ass が個人で使う Claude Code の mod のマーケットプレイスです。

| mod | 内容 |
|---|---|
| `status-board` | モデルが要約したステータスボードと指示ごとの履歴をペインに表示し、現在の状況をプロンプトの上に 1 行で表示する |

## インストール

```text
/plugin marketplace add p1ass/claude-plugins
/plugin install status-board@p1ass-plugins
```

## status-board

`/board` を実行するか、プロンプトの上にある「ステータスボード」のボタンを押すと、ペインを開閉します。

### ステータスボード

会話を引き継いだモデルが、ツールなしで 1 回だけ回答して、セッションを次の 5 つの見出しで要約します。

- 目的
- 判断待ちの事項
- 現状
- 決定事項
- 次の作業

要約するのは次の 3 つの場面です。

| 場面 | 条件 |
|---|---|
| ターンが回答で終わったとき | ペインを表示している |
| ペインを開いたとき | ボードがないか古く、最後のターンの終了から 5 分以内 |
| 「ステータスボードを更新」を押したとき | 常に要約する |

最後のターンの終了から 5 分を過ぎると、会話のキャッシュが失効している可能性があり、要約の費用が増えます。そのため、ペインを開いたときの自動の要約は 5 分以内に限ります。

ボードはセッションごとに保存し、8 日間更新のないボードは削除します。

### プロンプトの上の 1 行と履歴

プロンプトの上の 1 行と履歴は、セッションのトランスクリプトから次のイベントを読み取って表示します。

- 人間が入力した指示
- `AskUserQuestion` の質問
- PR の関連付け
- 計画と手順（デスクトップアプリのセッションだけ）
- 報告（デスクトップアプリのセッションだけ）

プロンプトの上の 1 行には、実行中の手順があればその手順を、なければ最新のイベントを表示します。履歴は指示ごとのカードで、最新の 5 件を表示します。

## 開発

mod を編集したら、Claude Code で `/reload-plugins` を実行すると反映されます。テストは次のコマンドで実行します。

```bash
claude plugin test plugins/status-board
```
